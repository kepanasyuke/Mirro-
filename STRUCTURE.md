# Структура проекта Mirro

Верхнеуровневая навигация по репозиторию. Для всех функций см. `CODE_MAP.md`.

## Папки

| Папка | Что это | Ключевые файлы |
|---|---|---|
| `algos/` | Библиотека алгоритмов + «нейробиология» | `think.py`, все `NN_*.py`, нейро-модули |
| `core/` | Ядро: HTTP-сервер, маршрутизация ответов | `mirro_core.py` |
| `scripts/` | Инфраструктура: поиск, RAG, генерация корпуса, обучение | `algorithms.py`, `rag.py`, `providers.py` |
| `tests/` | Юнит- и интеграционные тесты (unittest) | `test_*.py` |
| `tools/` | Инструменты разработчика | `check_duplicates.py` |
| `web/` | Фронтенд | `index.html`, `meysto-neiroset.html`, дашборд |
| `data/` | Корпуса и данные (не коммитится большая часть) | `processed/`, `corpus_big/` |
| `models/` | Кэши индекса и графа (не коммитится) | `index_cache.pkl`, `knowledge_graph.pkl` |
| `backups/`, `keys/`, `restore/` | Шифрованные бэкапы и ключи (не коммитятся) | — |

## Как писать код?

- Принципы: **структурное программирование** (один выход из функции, без `continue`),
  маленькие функции 2–3 строки, декораторы — только там где реально нужно (см. `LINTER.md`).
- Порядок маршрутизации `try_*` в ядре и реестр функций — см. `CODE_MAP.md`.
