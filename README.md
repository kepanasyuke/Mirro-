# Mirro — Эволюционная нейросеть знаний

Самообучающаяся нейросеть с собственной базой знаний (2.8 млн примеров) + дисковый RAG-индекс (4.8 млн). Работает полностью локально, без внешних API и библиотек вроде numpy.

## Быстрый старт

```
mirro_launcher.pyw          # ← одна кнопка, браузер сам откроется
python core/mirro_core.py   # или напрямую
```

После запуска: **http://127.0.0.1:3443**

## API (OpenAI-совместимый)

```
POST /v1/chat/completions  — ответ на вопрос (с reasoning)
POST /v1/feedback          — лайк/дизлайк (обучает перцептрон)
POST /v1/self-learn        — автономное обучение
GET  /health               — статус: 2.8M примеров, метрики
GET  /catalog.json         — каталог датасетов
```

## Как работает ответ

1. **Мыслительный движок** (algos/think.py) — распознаёт: вычисления, уравнения, комбинаторику, физику, НОД/НОК, проценты
2. **Обдумывание** — кандидаты проверяются: пересечение ключевых слов, jaccard-штраф за повтор вопроса, длина ответа
3. **RAG-поиск** — полный корпус (4.8M) на диске, сегменты подгружаются только по запросу
4. **TF-IDF + BM25** — быстрый поиск по 1.5M in-memory + перцептронная фильтрация
5. **Веб-поиск** — Wikidata + Wikipedia (RU/EN) для актуальных тем
6. **Алгоритм включения** — решает: direct / base / web / learn
7. **Фоллбэк на провайдера** — если база и веб пусты: DeepSeek (легальный, из РФ), ключ из env или `core/providers_secret.json`

## Алгоритмы

### Собственные (все на чистом Python)
- **TF-IDF + BM25** — поиск с нормализацией длины документа
- **TextRank** — суммаризация через PageRank на графе предложений
- **Naive Bayes** — классификация по 6 кластерам
- **Перцептрон** — 1-слойная нейросеть, обучение на лайках
- **Стемминг** — Porter-style для русского и английского
- **Детектор галлюцинаций** — TF-IDF проверка фактов
- **Self-correction** — повторный поиск при низкой оценке
- **KeyBERT** — выделение ключевых слов через TF-IDF

### Algolib (28 модулей)
статистика, NLP, поиск, сортировки, строки, графы, матан, DP, комбинаторика, физика, вероятность, булева алгебра, кванты, гильбертовы пространства, университетские задачи, юмор, рассуждения, схемы Босовой, история ИИ + нейро-модули (см. архитектуру)

### «Нейробиология» (инновационные алгоритмы)
- **Знаниевый граф** — понятия как точки, связи как рёбра; отвечает «что связывает X и Y»
- **Объёмный мета-граф и роу-ссылки** — расширение знаниевого графа: взаимосвязи между самими связями (`graph.meta_routes`). Роу-ссылка «ребро→ребро» может на лету гасить (mod<0) хаотичную ветку или усиливать (mod>0) точную логическую цепочку — устраняя «кашу» при генерации.
- **Нульмерный граф + рост понимания (0D→3D)** — метрика топологической сложности сети. Изолированное понятие = 0D-точка, плоские связи = 1D, плотные кластеры = 2D, управляемые роу-ссылками = 3D. Роу-ссылки повышают мерность узла.
- **Нейромедиаторы и химическая модуляция** — дофамин/серотонин/норадреналин/ацетилхолин модулируют стиль ответа и проводимость рёбер: ацетилхолин сужает фокус, серотонин стабилизирует амплитуду, дофамин управляет шагом обучения.
- **Нейроэлектричество и мета-Хебб обучение** — «импульс» бежит по графу знаний с затуханием; лайки/дизлайки из `/v1/feedback` укрепляют или ослабляют рёбра пути по закону Хебба (`hebbian_update_path`).
- **Физический регулятор PINN** — энергетический цензор (`calculate_physics_loss`): штрафует хаотичные всплески, нарушающие константы среды; ответы выдаются только из физически стабильных паттернов.
- **Сквозной роу-контур** — `try_route_pipeline`: биометрия → модулированные рёбра → роу-импульсы → PINN → ответ.
- **ТТЛ-извлечение и консолидация опыта** — из текста RAG-индекса вытаскивает триплеты (S→P→O) и кормит граф; успешные латентные паттерны сохраняются в Базу Опыта (`remember_pattern`).
- **Нейроэволюция** — `evolve.py`: популяция графов, мутация и скрещивание весов, отбор по fitness (физичность + энергия), лучший паттерн пишется в память.
- **База знаний по функциям** — `module_knowledge.py`: 125+ функций алгоритмов с темой, описанием и примером; отвечает «что делает X / объясни Y».
- **Детектор новизны** — честно сообщает «это новое для меня», а не выдумывает

### Обучение
- Автономное обучение каждые 60 мин (self-question loop)
- Feedback loop: лайк → перцептрон → веса
- Планировщик автообучения в core/mirro_core.py

## Данные

- **2.8M** примеров в processed/ (ru 653k, math 200k, code 20k, design 6.6k, general 30k, generated 1.9M)
- **4.8M** сгенерированных примеров в corpus_big/ (дисковый RAG)
- **143 датасета** в каталоге (HuggingFace, MIT/Apache/CC-BY)
- RAG-индекс: 10 дисковых сегментов, 27k словарь глобального индекса

## Тесты

Набор юнит- и интеграционных тестов на стандартном `unittest` (без внешних
зависимостей). Запуск:

```
python -m unittest discover -s tests -v
```

Покрывает: движок мышления (`algos/think.py`), reasoning-кластеризацию,
голос/характер (`scripts/voice.py`), провайдеров (`scripts/providers.py`),
хелперы ядра и живой API (health, чат, модели, обработка ошибок). Тесты
интеграции с живым API пропускаются, если сервер Mirro не запущен.
