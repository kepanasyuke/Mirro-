# Mirro — Эволюционная нейросеть знаний

Самообучающаяся нейросеть с собственной базой знаний (2.8 млн примеров) + дисковый RAG-индекс (4.8 млн). Работает полностью локально, без внешних API и библиотек вроде numpy.

## Быстрый старт

```
mirro_launcher.pyw          # ← одна кнопка, браузер сам откроется
python core/mirro_core.py   # или напрямую
```

После запуска: **http://127.0.0.1:3443**

## API (OpenAI-совместимый)

```
POST /v1/chat/completions  — ответ на вопрос (с reasoning)
POST /v1/feedback          — лайк/дизлайк (обучает перцептрон)
POST /v1/self-learn        — автономное обучение
GET  /health               — статус: 2.8M примеров, метрики
GET  /catalog.json         — каталог датасетов
```

## Как работает ответ

1. **Мыслительный движок** (algos/think.py) — распознаёт: вычисления, уравнения, комбинаторику, физику, НОД/НОК, проценты
2. **Обдумывание** — кандидаты проверяются: пересечение ключевых слов, jaccard-штраф за повтор вопроса, длина ответа
3. **RAG-поиск** — полный корпус (4.8M) на диске, сегменты подгружаются только по запросу
4. **TF-IDF + BM25** — быстрый поиск по 1.5M in-memory + перцептронная фильтрация
5. **Веб-поиск** — Wikidata + Wikipedia (RU/EN) для актуальных тем
6. **Алгоритм включения** — решает: direct / base / web / learn
7. **Фоллбэк на провайдера** — если база и веб пусты: DeepSeek (легальный, из РФ), ключ из env или `core/providers_secret.json`

## Алгоритмы

### Собственные (все на чистом Python)
- **TF-IDF + BM25** — поиск с нормализацией длины документа
- **TextRank** — суммаризация через PageRank на графе предложений
- **Naive Bayes** — классификация по 6 кластерам
- **Перцептрон** — 1-слойная нейросеть, обучение на лайках
- **Стемминг** — Porter-style для русского и английского
- **Детектор галлюцинаций** — TF-IDF проверка фактов
- **Self-correction** — повторный поиск при низкой оценке
- **KeyBERT** — выделение ключевых слов через TF-IDF

### Algolib (16 модулей)
статистика, NLP, поиск, сортировки, строки, графы, матан, DP, комбинаторика, физика, вероятность, булева алгебра, кванты, гильбертовы пространства, университетские задачи

### Обучение
- Автономное обучение каждые 60 мин (self-question loop)
- Feedback loop: лайк → перцептрон → веса
- Планировщик автообучения в core/mirro_core.py

## Данные

- **2.8M** примеров в processed/ (ru 653k, math 200k, code 20k, design 6.6k, general 30k, generated 1.9M)
- **4.8M** сгенерированных примеров в corpus_big/ (дисковый RAG)
- **143 датасета** в каталоге (HuggingFace, MIT/Apache/CC-BY)
- RAG-индекс: 10 дисковых сегментов, 27k словарь глобального индекса
