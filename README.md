# Mirro — Эволюционная нейросеть знаний

Самообучающаяся нейросеть с собственной базой знаний, работающая полностью локально, без внешних API и библиотек вроде numpy.

## Архитектура

```
Mirro/
├── algos/          — Алгоритмы: статистика, NLP, поиск, ML, графы, матан, физика, кванты, семантика
├── core/           — Ядро: HTTP-сервер (OpenAI-совместимый API), классификатор, роутинг
├── data/           — Данные: processed/ (кластеры знаний), corpus_big/ (корпус), raw/ (исходники)
├── models/         — Индексы: pickle-кэш быстрого поиска, RAG-индексы сегментов
├── scripts/        — Скрипты: algorithms.py (TF-IDF, TextRank, NB, перцептрон), ingest, генерация
└── web/            — Фронтенд: одностраничный HTML-интерфейс
```

## Запуск

```bash
python core/mirro_core.py
```

Открой в браузере: http://127.0.0.1:3443

## API (OpenAI-совместимый)

```
POST /v1/chat/completions  — ответ на вопрос
POST /v1/feedback          — оценка ответа (обучает перцептрон)
POST /v1/self-learn        — автономное обучение
GET  /health               — статус системы
```

## Технологии

- Чистый Python, без numpy, без requests, без внешних API
- TF-IDF + BM25 поиск
- TextRank суммаризация
- Naive Bayes классификация
- Перцептрон (обучается на оценках пользователя)
- Детектор галлюцинаций
- Веб-поиск (Wikipedia/Wikidata)
- Двухуровневый RAG-индекс для больших корпусов
- Автономное обучение каждые 60 мин
