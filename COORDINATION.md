# Координация чатов по Mirro

Несколько чатов работают в одном репозитории одновременно. Этот файл — общая
точка правды: кто что трогает, что уже сделано, что дальше и как не передавить
друг друга. Правила короткие, потому что их должны читать и люди, и агенты.

## Правила

1. Перед правкой: `git status` и этот файл. Если файл в чужой зоне — не трогать,
   писать в свою зону или предложить изменение владельцу.
2. Не переформатировать файлы целиком: большие файлы (`algos/english_kb.py`,
   `core/mirro_core.py`) правятся точечно.
3. Коммит — одна логическая пачка, сообщение в стиле истории репозитория
   (`english_kb: … + tests; SYNTAX OK`).
4. Перед коммитом: `python scripts/build_mirro.py --check` и точечные тесты
   своей зоны. Полный прогон — партиями по 5 файлов (`MemoryError` на сборе).
5. Не пушить чужие незакоммиченные файлы «за компанию»: `git add` только своих.
6. Взял задачу — допиши строку в «В работе», закончил — убери.

## Зоны (кто владеет файлами)

| Зона | Файлы | Что там |
|---|---|---|
| База знаний | `algos/english_kb.py`, `algos/english_kb_part*.py` | темы, срезы; `tools/normalize_english_kb.py` держит их в срезах |
| Ядро и ответ | `core/mirro_core.py` | цепочка обработчиков `try_*`, маршрутизация ответа |
| Понятия и язык | `algos/concepts.py`, `algos/neuro_answer.py`, `algos/bilingual.py`, `algos/ru_bridge.py`, `algos/concept_graph.py`, `algos/answer_router.py`, `tools/ru_coverage.py` | русско-английский доступ к понятиям, граф связей, выбор ответа |
| Семантика | `algos/embeddings.py`, `algos/information.py` | PPMI-эмбеддинги, энтропия/PMI |
| Граф знаний | `algos/knowledge_graph.py`, `algos/quantum_graph.py` | русский граф, связи, вывод |
| Корпус | `scripts/rag.py`, `scripts/clean_corpus.py`, `scripts/ingest_data.py`, `scripts/ru_definitions.py` | поиск и добыча определений |
| Интерфейс | `web/*` | страницы и инлайн-JS |
| Тесты | `tests/*` | свои тесты держим рядом со своей зоной |
