# Мирro на PHP

Тонкая PHP-обёртка вокруг живого API Мирro (OpenAI-совместимый, порт 3443).
Ядро Мирro остаётся на Python — PHP здесь только «мост» и «эхо».

## Файлы

- `index.php` — мини-чат: форма, история диалога в сессии, кнопка «Очистить».
- `../mirro_perceptron_php.php` — учебная игрушка: один нейрон (перцептрон) учит AND-gate на чистом PHP, как эхо настоящего перцептрона Мирro на Python.

## Как запустить

1. Установить PHP (7.4+), например с https://windows.php.net/ или через пакетный менеджер.
2. Запустить Мирro: `mirro_launcher.pyw` (сервер на 127.0.0.1:3443).
3. В папке `web/mirro-php` запустить встроенный сервер PHP:

```bash
php -S 127.0.0.1:8090
```

4. Открыть http://127.0.0.1:8090 — и спросить Мирro.

Опционально: перцептрон-игрушка из консоли:

```bash
php -S 127.0.0.1:8090 -t ..
# или напрямую в CLI:
php web/mirro_perceptron_php.php
```

## Зависимости

- PHP 7.4+;
- `curl` ИЛИ `allow_url_fopen=On` (есть fallback на `file_get_contents`);
- запущенный сервер Мирro (127.0.0.1:3443);
- CORS у Мирro открыт (`Access-Control-Allow-Origin: *`).
