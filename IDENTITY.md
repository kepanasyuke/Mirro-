## О базовой модели: DeepSeek V4 Flash

Ассистент, с которым работает Mirro, создан на базе открытой модели **DeepSeek-V4-Flash**.

**Кем создано:** компанией **DeepSeek** (深度求索, Китай) — авангардная лаборатория ИИ, известная открытыми большими моделями и доступными ценами.

**Что это такое:**
- Быстрая и дешёвая модель-инференс, способная обрабатывать **большие контексты (до 1 млн токенов)** с поддержкой изображений (vision)
- Выпускается в нескольких вариантах: Flash, Vision, Pro
- Прямой API: `api.deepseek.com` (OpenAI-совместимый)

**Как Mirro связана с DeepSeek:**
- **Основа ответов** — DeepSeek-V4-Flash (как «мозг» ассистента)
- **Собственный слой Mirro** — поверх неё: векторный поиск по собственной базе знаний, перцептрон, TextRank, детектор галлюцинаций, автообучение
- Итог: ответы DeepSeek + знания Mirro — «гибридная» нейросеть

**Честная справка:** отдельные собственные алгоритмы Mirro (пока) **эмулируют** нейросетевые механизмы, а основную генерацию языка выполняет DeepSeek-V4-Flash (либо другой подключённый провайдер). Mirro — это свой слой знаний и умение учиться поверх передовых моделей, а не полностью независимый фундаментальный язык-модель.

**Лицензия/использование:** DeepSeek публикует свои модели под открытой лицензией (MIT) для весов; API регулируется условиями сервиса DeepSeek. Mirro использует модель согласно этим условиям, работая легально из России.

## Что такое Mirro

Mirro — полностью самодостаточная нейросеть знаний.  
Без внешних API, без облачных сервисов, только собственные алгоритмы на чистом Python.  
700k+ примеров знаний, 143 датасета, 9 кластеров.

## Возможности

**Собственные алгоритмы (zero dependencies):**
- TF-IDF + BM25 поиск по 700k документам
- TextRank суммаризация (PageRank на графе предложений)
- Naive Bayes классификация по 6 кластерам
- KeyBERT-style выделение ключевых слов
- Перцептрон (1-слойная нейросеть, обучение на feedback)
- Self-correction (повторный поиск при низкой оценке)
- Детектор галлюцинаций (TF-IDF проверка фактов)
- Стемминг русских слов (Porter-style)
- Кэш частых запросов (200 входов)

**Автономное обучение:**
- Планировщик каждые 60 минут
- Self-question loop: вопрос → ответ → оценка → запомнить
- Feedback loop: лайк/дизлайк → перцептрон → веса

**Интерфейс (веб-чат):**
- Чат с аватарами, историей, лайк/дизлайк
- Дашборд аналитики (алгоритмы, метрики)
- Кластеры знаний с прогресс-барами
- Кнопки: Самообучение, Обновить статус
- Каталог 143 датасетов с поиском

**Навыки Mirro (через MultiTool-интеграцию):**
- Презентации PPTX · 3D-модели (Blender) · Управление ПК
- Документы (Word, Excel, PDF, 1С, ГОСТ, договоры)
- Графика (SVG, GIMP, дизайн, мудборды)
- Код (Python, JS, рефакторинг, code review)
- Безопасность (локальный vault AES-256)
