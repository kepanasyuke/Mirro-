## О базовой модели: DeepSeek-V4-Flash

Ассистент, с которым работает Mirro, создан на базе открытой модели **DeepSeek-V4-Flash**.

**Кем создано:** компанией **DeepSeek** (深度求索, Китай) — лаборатория ИИ, известная открытыми моделями.

**Что это такое:**
- Быстрая модель-инференс, контекст **до 1 млн токенов**
- Выпускается в вариантах: Flash, Vision, Pro
- Прямой API: `api.deepseek.com` (OpenAI-совместимый)

**Как Mirro связана с DeepSeek:**
- **Основа ответов** — DeepSeek-V4-Flash (как «мозг» ассистента)
- **Собственный слой Mirro** — поверх неё: векторный поиск по 2.8M примеров, перцептрон, TextRank, детектор галлюцинаций, автообучение, RAG-индекс на 4.8M
- Итог: «гибридная» нейросеть — DeepSeek + собственные знания Mirro

**Честная справка:** отдельные собственные алгоритмы Mirro **эмулируют** нейросетевые механизмы, а основную генерацию языка выполняет DeepSeek-V4-Flash (либо другой подключённый провайдер). Mirro — свой слой знаний поверх передовых моделей.

**Лицензия/использование:** DeepSeek публикует модели под открытой лицензией (MIT) для весов; API регулируется условиями сервиса DeepSeek. Mirro работает легально из РФ.

## Что такое Mirro

Mirro — полностью самодостаточная нейросеть знаний.  
Без внешних API, без облачных сервисов — только собственные алгоритмы на чистом Python.  
**2.8M+ примеров знаний, 143 датасета, 6 кластеров.**

## Возможности

**Собственные алгоритмы (zero dependencies):**
- TF-IDF + BM25 поиск по 2.8M документам
- TextRank суммаризация (PageRank на графе предложений)
- Naive Bayes классификация по 6 кластерам
- KeyBERT-style выделение ключевых слов
- Перцептрон (1-слойная нейросеть, обучение на feedback)
- Self-correction + обдумывание ответов (reasoning step)
- Детектор галлюцинаций (TF-IDF проверка фактов)
- Стемминг русских слов (Porter-style)
- Кэш частых запросов (200 входов)
- Дисковый RAG-индекс (4.8M примеров, 10 сегментов)

**Автономное обучение:**
- Планировщик каждые 60 минут
- Self-question loop: вопрос → ответ → оценка → запомнить
- Feedback loop: лайк/дизлайк → перцептрон → веса

**Интерфейс (веб-чат):**
- Чат с аватарами, историей, лайк/дизлайк
- Дашборд аналитики (алгоритмы, метрики)
- Кластеры знаний с прогресс-барами
- Каталог 143 датасетов с поиском
- GUI-загрузчик (mirro_launcher.pyw)

**Навыки Mirro (через MultiTool-интеграцию):**
- Презентации PPTX · 3D-модели (Blender) · Управление ПК
- Документы (Word, Excel, PDF, 1С, ГОСТ, договоры)
- Графика (SVG, GIMP, дизайн, мудборды)
- Код (Python, JS, рефакторинг, code review)
- Безопасность (локальный vault AES-256)
- Защищённые бэкапы (decimal cipher: files ← → .dec, ключ-документ отдельно)
- Мейсто (web/meysto-neiroset.html): «Собери нейросеть из блоков» + «Мозг Мирро» (реальный перцептрон) + живой «Спросить Мирро»
